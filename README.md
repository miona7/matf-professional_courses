# 🎓 Miona – MATF Professional Courses Repository

This repository contains materials, assignments, and exercises related to **professional courses** I am attending alongside my studies at the **Faculty of Mathematics, University of Belgrade**.  

The goal of this repository is to centralize all course-related work in one place, track progress, and maintain an organized collection of study materials for future reference.

---

## 📂 Structure

The repository is organized by courses:

- 💻 **ENDAVA - Fundamentals of Software Testing**   
  Exercises, assignments, and templates covering foundational concepts of software testing, including test case design, test execution, reporting, and the use of professional testing tools.

- ☁️ **RIVIAN - Cloud Application Development (Amazon Web Services)**     
  Focuses on building and deploying scalable applications using AWS services. Final project completed as a requirement for passing the course: [⚡ EV Chargers Map](https://github.com/miona7/MATF-RVTECH-AWSCLOUD-2025)    

- ⚙️ **HTEC - Program Compilers for Machine Learning**     
  Deep dive into compiler optimizations and architecture specifically designed to enhance performance for machine learning workloads and high-performance computing.    

- 📈 **Levi9 - IT Project Management in Practice**    
  Hands-on experience with Agile methodologies, Scrum, project planning, and the essential soft skills required for successful project delivery in a professional environment.
